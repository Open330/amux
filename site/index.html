Your agents keep working. Your workspaces keep existing.

One durable model

tmux owns the session. amux owns the experience.

Close the window, detach with your prefix, reconnect over SSH, or attach from another terminal. The shell remains a tmux session while amux projects it into fast native Ghostty surfaces.

Built for agent work

See the whole run without babysitting every pane.

01 / persist

tmux-native workspaces

A workspace maps to a dedicated tmux session. Pane topology, scrollback, and processes survive the app.

02 / observe

muxa agent state

Working, waiting, choice, and error states are correlated with tmux panes and surfaced in one place.

03 / attend

Jump to what needs you

Cmd+Shift+J moves directly to the longest-blocked agent instead of making you scan every terminal.

04 / connect

Local, tmux, and SSH

Cmd+K separates and searches ordinary shells, local tmux sessions, and remote sessions.

05 / automate

One CLI and socket API

Create splits, send prompts, read screens, route notifications, and drive browsers without stealing focus.

06 / render

Native Ghostty surfaces

No nested tmux chrome and no Electron. amux renders the session directly with a native macOS interface.

Install amux 0.2.0

Start with the signed macOS release.

Homebrew

Homebrew 6 asks you to trust third-party taps before loading their casks.

brew tap Open330/tap
brew trust Open330/tap
brew install --cask Open330/tap/amux
Updates continue through the cask and amux's built-in Sparkle updater.

DMG

Download the notarized image, open it, and drag amux to Applications.
